## Abra uma conversa
1. Acesse **Conversas** no menu.
2. Use os filtros disponíveis para localizar todos os atendimentos, os seus ou os que estão sem responsável.
3. Selecione um contato na lista.
4. Confira as mensagens e os dados do contato antes de responder.

A busca da lista atua sobre as conversas já carregadas. Carregue mais itens quando necessário. Uma mensagem que falhar no envio pode manter o texto no campo para nova tentativa.

## Atribua atendimento humano
1. Abra a conversa.
2. Clique no ícone de pessoa ou no avatar do responsável no cabeçalho.
3. No modal **Atribuir atendimento humano**, selecione o atendente.
4. Aguarde a confirmação. O avatar do responsável é atualizado após o salvamento.

O usuário logado aparece como **Você** quando está habilitado a receber conversas. A lista inclui pessoas ativas da clínica que podem receber atendimentos. Quando não há foto disponível, o avatar usa iniciais.

## Não consigo atribuir
A conversa precisa estar aberta. As permissões de transferência dependem do seu perfil e de quem já é responsável. Um atendente pode assumir uma conversa sem responsável para si; a gestão pode atribuir conforme suas permissões.

Se uma pessoa não aparecer, peça ao administrador para verificar se está ativa e habilitada para receber conversas.

## Mostrar dados do contato
Use o ícone de ficha de contato no cabeçalho para abrir os dados disponíveis, como nome, telefone, etapa e responsável.
